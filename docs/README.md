# Documentación técnica de DBDesigner

Documentación para desarrollar el proyecto. La documentación de uso está en el [README principal](../README.md) y el resumen que se carga en cada sesión de trabajo, en [CLAUDE.md](../CLAUDE.md).

| Documento | Léelo cuando vayas a… |
|---|---|
| [arquitectura.md](arquitectura.md) | Entender cómo encajan las piezas, añadir un módulo o tocar el arranque |
| [modelo-y-estado.md](modelo-y-estado.md) | Cambiar el modelo de datos, añadir una acción al store, tocar la persistencia o el JSON |
| [canvas.md](canvas.md) | Tocar el diagrama: zoom, cámara, niveles de detalle, arrastre, render, rendimiento |
| [relaciones.md](relaciones.md) | Cambiar cómo se dibujan o enrutan las relaciones, la notación o las tablas N:M |
| [sql.md](sql.md) | Cambiar el SQL generado o el importador de DDL |
| [editor-de-tablas.md](editor-de-tablas.md) | Cambiar la creación o edición de tablas |
| [interfaz.md](interfaz.md) | Tocar el panel lateral, modales, atajos, temas, avisos o la exportación PNG |
| [desarrollo.md](desarrollo.md) | Escribir tests, verificar en el navegador o consultar limitaciones y pendientes |

## Mantenimiento

Cada cambio de comportamiento debe reflejarse en el documento del sistema afectado (y en el README si lo nota el usuario). Si un documento contradice al código, manda el código: corrige el documento.
